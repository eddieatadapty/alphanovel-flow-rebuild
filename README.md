# AlphaNovel Growth Audit

**Live → https://eddieatadapty.github.io/alphanovel-flow-rebuild/**

Five ideas to turn more AlphaNovel users into subscribers, each built into a clickable version of AlphaNovel's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show Plus inside the onboarding, at the end of chapter one | +15–30% CR to purchase |
| 02 | Use the answers you collect | +5–15% CR to purchase |
| 03 | Sell Plus in chapters, with 84K ratings behind it | +5–10% CR to purchase |
| 04 | Catch the people who close the paywall | +5–10% ARPU |
| 05 | Ask two questions, not five | +3–8% CR to purchase |

Every price, rating and feature comes from AlphaNovel's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for AlphaNovel. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
